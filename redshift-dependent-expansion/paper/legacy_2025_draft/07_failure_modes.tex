\section{Failure Modes}

If H0-CDR beats vanilla $\Lambda$CDM but fails against method-specific or
candidate-specific nuisance baselines, the calibration-domain interpretation is
not supported. In-sample $\chi^2$ improvement over vanilla $\Lambda$CDM is
insufficient; the model must also improve held-out prediction.

Other failure modes:
\begin{itemize}
  \item The candidate selector activates for methods it should not (resolved by
    linear transform with zero-feature $\to$ zero-activation).
  \item Fixture data encode the very split being tested, producing circular
    confirmation.
  \item All-zero feature values for a candidate make scoring uninformative
    (candidates are skipped with reason \texttt{all\_zero\_feature\_values}).
  \item Propagation-null tests fail, indicating the model absorbs calibration
    structure rather than predicting it.
\end{itemize}
