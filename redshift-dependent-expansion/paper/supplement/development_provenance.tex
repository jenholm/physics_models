\section{Development provenance (supplement)}
\label{sec:development-provenance}

This supplement records the internal development labels used during
the investigation. These labels are \emph{not} scientific variables
in the main analysis; they name dated fitting stages, optimizer
diagnostics, and frozen evidence directories. The main text uses only
R (distance-compatible endpoint), C1 (first Planck-compatible
endpoint), C2 (second Planck-compatible endpoint), and m3 (selected
compact reconstruction basis).

\subsection{Historical development labels}

\begin{itemize}
\item M28 $\to$ predecessor fitting program that produced the
coordinates from which R (the smooth low-redshift control history)
was pinned. M28 headline values ($\chi^{2}=1450.558$,
$H_{0}\sim73.01$, $r_{d}\sim135.62$) are \emph{not} R values and are
not used as scientific variables in the main analysis.
\item B2 $\to$ predecessor full-CMB branch program that produced C1
(the stage-0 $\Lambda$CDM background tuned to Planck TT/TE/EE).
In the main text, Model~A detail refers to the distance-branch
construction behind R and Model~B2 detail to the CMB-branch
construction behind C1.
\item M24, M26A (G10 late-time baseline), R131 (penalty-homotopy
optimizer diagnostic), R4V (visible-bridge reconstruction stage),
R5 (paper-cycle reconstruction stage), R6 (three-branch comparison
stage): dated analysis stages whose frozen evidence lives under
\path{runs/cmb_bridge/} and \path{paper/evidence/cmb_bridge_*};
only their frozen outputs (R, C1, C2, m3) enter the main analysis.
\end{itemize}

\subsection{Why history is preserved}

Earlier stages contain the optimizer-start records, boundary audits,
adversarial controls (roughness family, $m=6$ overfit), and the
full stage-by-stage narrative (Appendix~A). They are preserved so
that the path to the frozen endpoints can be audited, not because
the main empirical claims depend on them. No result in
Sections~\ref{sec:data-endpoints}--\ref{sec:conclusion} is fitted,
selected, or tuned using these labels.

\subsection{Historical symbols (supplement only)}

The following symbols appear only in frozen evidence, code, and this
supplement — never as scientific variables in the main analysis.

\begin{itemize}
\item $A_{E}$: historical early-epoch amplitude of the predecessor
  M28 construction (failed full Planck).
\item $q_{l0},q_{l1},q_{l2}$, $q_{\rho0},q_{\rho1},q_{\rho2}$:
  historical duration/width logits of the predecessor optimizer.
\item $x_{1},x_{2}$: historical late-mapping coordinates, fixed to
  zero by repair.
\item $g_{0},g_{1}$: historical broad-backbone coordinates.
\item $t_{0},\ldots,t_{9}$: historical late-time temporal modes.
\item M24, M26A, R131, G10, R4V, R5, R6: dated analysis stages (see
  above); see the endpoint identity contract for the R vs Model~A
  distinction.
\end{itemize}
