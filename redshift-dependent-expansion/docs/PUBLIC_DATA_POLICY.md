# Public data policy

- No proprietary or private data are stored in this repository.
- No raw Pantheon/DESI/Planck catalog data are redistributed beyond
  what their licenses permit; publication evidence contains derived
  quantities and hashes only.
- No local absolute paths, no credentials, no secrets.
- The simulation contains synthetic tracers only (generated at runtime
  from a fixed seed); no observed-catalog rows are embedded.
- Source data citations:
  - DESI DR2 BAO (Results II) and the DR2 Lyman-alpha companion
    (Results I) for the BAO likelihood including the z = 2.33 anchor;
  - Pantheon+SH0ES for the supernova likelihood;
  - Planck 2018 (full TT/TE/EE spectra) for the C1/C2 references, and
    the Chen et al. compressed distance prior as used during endpoint
    discovery only (validated for conventional late-time models; not
    used as evidence for nonstandard physics).
